How this works

A lesson is one JSON file with each segment in every supported language. English and Hindi are hand-authored; Tamil, Telugu and Bengali are a content gap that the translation service closes on first read and caches in SQLite. Every tap, question and answer appends a row to an append-only event log, which is what the dashboard reads. One loop, one source of truth.
